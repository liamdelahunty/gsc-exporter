1 Tier 1: Mandatory Monday Morning Suite

These four reports form the non-negotiable Monday morning reporting rhythm. They must be executed first to generate the weekly editorial email and the group-wide Canary alerts.

Execution Objective: Run these four reports before 10:30 AM every Monday. They produce the two essential external deliverables: the Accountancy Daily Editorial Email (to editorial leads) and the Canary Email (to executive and analytical stakeholders).
1.1 Accountancy Daily Editorial Summary Report
GSC

Script: reports/weekly_editorial_summary_report.py | Directory: gsc-page-exporter

What it does: Dissects the trailing 7-day period for Accountancy Daily against the prior 7 days across Web Search, Google Discover, and Google News. It highlights the top performing stories, click distribution, and outputs a formatted summary table directly to the console.

Git Bash (Windows) 
cd "C:\Users\liam.delahunty\OneDrive - Peninsula Group Online\Documents\2. Areas\Code\gsc-page-exporter"
source .venv/Scripts/activate
python reports/weekly_editorial_summary_report.py sc-domain:accountancydaily.co
deactivate
Deliverables to Attach to Email: output/sc-domain-accountancydaily-co/weekly-editorial-summary-sc-domain-accountancydaily-co-YYYY-MM-DD-to-YYYY-MM-DD.csv & weekly-editorial-summary-sc-domain-accountancydaily-co-YYYY-MM-DD-to-YYYY-MM-DD-distribution.html
1.2 Google Search Console Canary Report
GSC

Script: reports/monitoring/canary_report.py | Directory: gsc-page-exporter

What it does: Early warning monitoring of organic search health across all 11 properties. Compares the latest 7 available days against the previous week (WoW) and previous month (MoM) for Clicks, Impressions, CTR, and Position.

Git Bash (Windows) 
cd "C:\Users\liam.delahunty\OneDrive - Peninsula Group Online\Documents\2. Areas\Code\gsc-page-exporter"
source .venv/Scripts/activate
python reports/monitoring/canary_report.py --config config/properties.json
deactivate
Generated Output: output/account/gsc-monitoring-YYYY-MM-DD.html (First of 3 Canary attachments).
1.3 & 1.4 GA4 Canary Reports (Medium & Source/Medium)
GA4

Script: reports/monitoring/weekly_canary_html.py | Directory: ga4-api-explorer

What it does: Evaluates active user traffic across all 11 GA4 properties comparing the last 7 days against: Last Week, Last Month, and Year-on-Year (YoY). Running with --source produces a second granular report detailing specific traffic sources (Google organic, direct, newsletter UTMs, partner domains).

Git Bash (Windows) 
cd "C:\Users\liam.delahunty\OneDrive - Peninsula Group Online\Documents\2. Areas\Code\ga4-api-explorer"
source .venv/Scripts/activate
python reports/monitoring/weekly_canary_html.py --config config/properties.json
python reports/monitoring/weekly_canary_html.py --config config/properties.json --source
deactivate
Generated Outputs: output/account/ga4-monitoring-YYYY-MM-DD-medium.html & output/account/ga4-monitoring-YYYY-MM-DD-source_medium.html (Second & third Canary attachments).

Tier 2: Alert Diagnostics (When Properties Turn Red or Amber)

When the Canary reports flag an anomaly (Amber: drop between -10% and -25%; Red: critical drop > -25%), do not guess the cause. Execute these specific diagnostic scripts from our repositories to pinpoint the root issue.

Diagnostic Decision Framework:
  • If Red in GSC & GA4 Organic: True SEO ranking or indexing decline. Run GSC Performance Analysis and Query-Page Attribution.
  • If Red in GA4 Direct/All Mediums: Probable tagging, cookie consent container, or site deployment outage. Run GA4 Landing Pages & Hostname reports.
  • If Red in GSC Discover only: Normal news cycle decay after a viral spike; verify with Search Type Performance.
2.1 GSC Performance Analysis (WoW Shift)
GSC

Purpose: Isolates whether a drop was driven by lost impressions (search demand drop or de-indexing) or lower click-through rate / falling positions.

gsc-page-exporter 
python reports/performance_analysis.py [SITE_URL] --last-7-days
Generates detailed delta metrics comparing the last 7 days vs previous 7 days.
2.2 GSC Queries & Pages Analysis (Keyword Loss)
GSC

Purpose: Unpacks query-level rankings for specific landing pages to see which exact search terms lost clicks.

gsc-page-exporter 
python reports/queries_pages_analysis.py [SITE_URL] --last-7-days
Maps search query intent directly to affected landing pages.
2.3 GSC Search Type Breakdown (Web vs Discover vs News)
GSC

Purpose: Verifies if traffic drops stem from Discover feed churn or standard Google Web Search fluctuations.

gsc-page-exporter 
python reports/page_level_report.py [SITE_URL] --search-type web --last-7-days
python reports/page_level_report.py [SITE_URL] --search-type discover --last-7-days
Runs isolated URL performance censuses for each channel.
2.4 GA4 Traffic Acquisition (Channel Shift)
GA4

Purpose: Audits all acquisition channels (Organic Search, Direct, Referral, Paid Search, Email) to see where sessions dropped.

ga4-api-explorer 
python run_report.py -p [PROPERTY_ID] -r traffic_acquisition_report -sd YYYY-MM-DD -ed YYYY-MM-DD -o html
Exports interactive HTML channel audit dashboard into output/.
2.5 GA4 Landing Pages Report (Top Droppers)
GA4

Purpose: Identifies the specific site sections or pages that lost active users or experienced elevated bounce/exit rates.

ga4-api-explorer 
python run_report.py -p [PROPERTY_ID] -r landing_pages_report -sd YYYY-MM-DD -ed YYYY-MM-DD -o html
Pinpoints exact user entry URLs during the reporting period.
2.6 GA4 Cross-Property AI Referral Report
GA4

Purpose: Audits all 11 properties for incoming traffic from AI chatbots and search engines (ChatGPT, Perplexity, Claude, Gemini, Copilot).

ga4-api-explorer 
python reports/all_properties_ai_traffic_report.py
Scans regex patterns across all properties and generates cross-property matrix.
