Croner-i Library Migration Reports Guide

An operational guide for executing, auditing, and interpreting Google Search Console migration reports during the migration of content from library.croneri.co.uk to the primary marketing site at www.croneri.co.uk.

Migration Objective: Identify high-traffic technical commentary and guidance on the Croner-i Library platform, audit them for search intent, map them to clean marketing URLs, and assess the organic performance of priority Quick Links.

1. Migration Architecture & Overview

The Croner-i Library contains deep technical legislation, commentary, and compliance guidance. The migration suite analyses how searchers discover this content and translates deep technical paths (such as CCH UK legislation nodes) into search-optimised marketing URLs on www.croneri.co.uk.

A core design principle of this suite is providing both Keywords Mode (with query breakdowns) and Page-Only Mode (unfiltered page traffic without Google privacy exclusion).

Script Name Outputs Generated Key Deliverable
library_marketing_migration_prioritisation_report.py 2 HTML reports & 2 CSV datasets Prioritised top 100 library pages with SEO disconnect audits (Keyword & Page-only versions)
library_marketing_migration_analysis.py 2 HTML reports & 2 CSV datasets Interactive mapping table connecting library URLs to proposed marketing paths
library_quick_links_performance_report.py 4 HTML reports Targeted analysis of 19 highlighted Quick Links and all quick links extracted from site navigation
generate_library_migration_index.py 1 HTML master index Unified navigation portal linking all 8 migration reports and associated CSV files

2. How to Run the Reports

Prerequisites

  • Google Search Console API access for https://library.croneri.co.uk/ (or domain property sc-domain:croneri.co.uk).
  • The quick links configuration files located in config/library-quick-links.html and config/library-quick-links.txt.

Execution Workflow

1 Library Prioritisation Reports

Produces both the standard prioritisation report (featuring driving query keywords and semantic disconnect warnings) and the unfiltered page-only prioritisation report. 

python reports/migrations/library_marketing_migration_prioritisation_report.py https://library.croneri.co.uk/ --last-month

Outputs: library-marketing-migration-prioritisation-report-*.html and library-marketing-migration-prioritisation-page-only-*.html.

2 Library Migration Analysis & Mapping

Generates the interactive mapping table matching deep technical articles to clean marketing slugs on the main site. 

python reports/migrations/library_marketing_migration_analysis.py https://library.croneri.co.uk/ --last-month

Outputs: library-marketing-migration-analysis-*.html and library-marketing-migration-analysis-page-only-*.html.

3 Quick Links Performance Suite

Processes the product owner Quick Links list across four separate report views (Highlighted Keywords, Highlighted Page-Only, All Keywords, All Page-Only). 

python reports/migrations/library_quick_links_performance_report.py https://library.croneri.co.uk/ --last-month

4 Compile Library Migration Index

Builds the master index page linking all eight reports and CSV files with an integrated navigation bar. 

python reports/migrations/generate_library_migration_index.py https://library.croneri.co.uk/ --last-month

Command-Line Arguments Reference

  • site_url: Defaults to https://library.croneri.co.uk/.
  • --last-month: Sets date range to the previous calendar month.
  • --last-7-days: Sets date range to the previous 7 days.
  • --start-date YYYY-MM-DD & --end-date YYYY-MM-DD: Custom historical date window.
  • --limit <int>: Maximum number of pages to display in HTML tables (default: 100).
  • --max-rows <int>: Maximum GSC API rows fetched before aggregation (default: 10,000 for analysis, 20,000 for quick links). Prevents API timeout on high-volume properties.

3. How to Read and Interpret the Results

A. Keywords Mode vs Page-Only Mode

Both the Prioritisation and Analysis reports produce two separate views. It is vital to know when to use each:

  • Keywords Mode (with queries):
    • Subject to Google Search Console privacy thresholds. Google anonymises low-volume queries, meaning total clicks shown may be lower than total actual site traffic.
    • When to use: Use this view to understand why users visit the page, what intent they have, and whether the page title matches their search query.
  • Page-Only Mode (unfiltered):
    • Requests GSC data using only the page dimension. Google does not strip privacy-filtered queries from page totals in this view.
    • When to use: Use this view for commercial prioritisation and technical redirection lists, as it reflects the true volume of organic visits landing on each URL.
B. Prioritisation Report & Semantic Disconnects

Focus Area: Top 100 library pages ranked by organic clicks.

  • Semantic Disconnect Detection: The report tokenises the original URL slug and compares it with the top queries driving search traffic.
    • If a technical library page is titled with an internal CCH reference code (e.g. /cch_uk/btc/100-200) but ranks for "capital allowances plant and machinery", a disconnect flag is raised.
    • This indicates that the marketing version on www.croneri.co.uk should use a clear, descriptive URL slug rather than legacy technical numbering.
  • Suggested Marketing Target: The script applies stop-word stripping, brand removal, and hyphen formatting to suggest a clean target URL (e.g. https://www.croneri.co.uk/capital-allowances-plant-machinery).
C. Library Migration Analysis Table

Focus Area: Interactive mapping and URL verification.

  • Interactive Drawers: Clicking on a table row reveals the top driving search keywords, impressions, CTR, and average position for that specific library asset.
  • Target URL Manual Overrides: If the programmatic slug generator creates an unsuitable target path, developers can add a manual mapping into the URL_OVERRIDES dictionary in library_marketing_migration_analysis.py.
  • Status Tracking: Allows teams to export the table to CSV to track content migration statuses (e.g. "Not Started", "In Review", "Published", "Redirected").
D. Quick Links Performance Reports

Focus Area: High-priority business topic hubs.

  • 19 Highlighted Quick Links: Focuses strictly on the core commercial hubs selected by product leadership (such as Company Purchase of Own Shares, Making Tax Digital, Business Asset Disposal Relief, FRS 102, and Annual Investment Allowance).
  • Performance Verification: These topic hubs often serve as flagship lead-generation pages. Verify whether these pages rank in top 3 positions for their head terms or if they suffer from ranking dilution.
  • All Quick Links View: Parses the complete library navigation tree to ensure no secondary topic guides are overlooked during migration scoping.

4. Recommended Migration Steps

  1. Establish the Monthly Benchmark: Run the complete suite with --last-month to obtain consistent baseline figures.
  2. Review the 19 Highlighted Quick Links First: Ensure all 19 priority hubs have dedicated new marketing landing pages scheduled on www.croneri.co.uk.
  3. Audit the Prioritisation Report Top 100: Address the top 100 pages to secure the vast majority of organic search impressions.
  4. Configure 301 Redirects from Page-Only CSVs: Provide developers with the Page-Only CSV datasets to map every technical library URL to its new marketing destination.
  5. Monitor Crawl & Ranking Recovery: Following redirect deployment, monitor whether Google transfers ranking positions and click volume from library.croneri.co.uk to www.croneri.co.uk.
